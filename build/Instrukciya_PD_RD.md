# 1. Назначение

PD_RD собирает комплект проектной (ПД) и рабочей (РД) документации на размещение волоконно-оптических линий связи на опорах воздушных линий филиала ПАО «Россети Юг» — «Кубаньэнерго» из отчёта по пункту 13 Правил (ПП РФ № 2106), подготовленного в АРМ ППО, технического задания оператора и проектных решений.

Инструмент работает в браузере (компьютер или iPad). Данные никуда не передаются и хранятся в браузере; резервная копия сохраняется в файл `.pdrd`.

Адрес: https://anatoliy031.github.io/PD_RD/

Два режима:

- **Разработка** — филиал выполняет ПИР для пользователя инфраструктуры;
- **Проверка** — филиал как владелец ВЛ рассматривает проект оператора и выдаёт лист замечаний (страница «Проверка проекта»).

# 2. Порядок работы

1. **Исходные данные.** Загрузите отчёт по п. 13 (`.docx`, выпущенный АРМ ППО) или резервную копию осмотра АРМ ППО (`.json`). Проверьте результат входного контроля, скачайте лист входного контроля и направьте запросы владельцу и пользователю. Нажмите «Принять в проект».
2. **Проект.** Заполните паспорт: шифр, подписи, заказчик, ТЗ, договор, СРО, правовые решения (разрешение, ДПТ, экспертиза) со ссылками на нормы, изыскания, состав разделов, документы на кабель, пересечения, метрологию.
3. **Расчёты.** Внесите климатические температуры (СП 131.13330.2020), паспорт кабеля (EA, α, МДРН), провода ВЛ по классам (данные владельца), размеры стоек и несущую способность анкерных опор по типовым проектам. Нажмите «Сохранить и рассчитать». Перечень недостающих данных показывается над результатами.
4. **Решения.** Задайте строительную длину, запас у муфт, длину пролёта для гасителей. Нажмите «Предложить решения» — программа примет решения по каждой опоре, подберёт высоты подвеса и пересчитает габариты. Исправьте решения вручную, где нужно (ручные решения помечаются и не перезаписываются).
5. **Муфты и запасы.** По умолчанию действует режим «вручную»: отметьте в столбце «Муфта» опоры, указанные заказчиком, выберите тип муфты и длину запаса. Поиск опоры по номеру — в поле над таблицей. Режим «автоматически» расставляет муфты в точках ветвления и на стыках строительных длин.
6. **Чертежи.** При необходимости загрузите растровую подложку ситуационного плана и укажите координаты её углов (как в Google Earth: «Добавить» → «Наложение изображения» → «Местоположение»); кнопка «Подставить углы по трассе» заполняет их по описанному прямоугольнику. Постройте листы, скачайте PDF и DXF. Подложка хранится в браузере и в файл проекта не входит.
7. **Спецификация.** Проверьте длины и количества; скачайте ведомости (XLSX) и трассу (KMZ).
8. **Выпуск.** На главной странице выполните аудит. Пока есть блокирующие несоответствия, доступен только черновой комплект (файлы с пометкой CHERNOVIK). После устранения несоответствий — «Выпустить комплект».

# 3. Шлюз выпуска

Каждое несоответствие блокирует выпуск. Обойти его можно только решением ответственного лица: обоснование не короче 40 символов и Ф.И.О. (например, «Куличкин Е.В.»). Решение сохраняется в проекте и печатается в листе внутреннего контроля (том «Иная документация»).

Не обходите решением отсутствие исходных данных для расчёта: без них выводы о несущей способности не обоснованы.

# 4. Состав комплекта

| Папка | Содержимое |
|---|---|
| 0_Vhodnoj_kontrol | Лист входного контроля исходных данных |
| 1_PD | Разделы 1–10 ПД по п. 32 Положения (ПП РФ № 87) |
| 2_RD | Том РД «Линейно-кабельные сооружения» (DOCX) и чертежи (PDF, А3) |
| 3_Chertezhi_DXF | Чертежи в DXF R12 — один лист, один файл |
| 3_Vedomosti | Ведомости и спецификация (XLSX), трасса (KMZ) |
| 4_Proekt | Файл проекта `.pdrd` |
| Opis.txt | Опись с размерами и контрольными суммами SHA-256 |

PDF текстовых томов получают в Word или «Р7-Офис» («Сохранить как PDF»); при открытии тома подтвердите обновление полей — проставятся номера листов в содержании.

# 5. Что запросить до выпуска

- у владельца ВЛ (ЭС): марка, число, диаметр, масса, высота подвеса, тяжение и наибольшая стрела проводов по каждому классу напряжения; паспорта ВЛ; ответы на запросы входного контроля;
- у пользователя (оператора): паспорт кабеля (EA, α, МДРН, срок службы, трекингостойкость), декларацию соответствия, техническую политику по запасам и муфтам;
- в филиале: утверждённые шифр и марки, каталог кабелей и арматуры, реквизиты СРО, Ф.И.О. «Разработал», «Проверил», «Н. контроль»;
- по типовым проектам серий 3.407.1-136, 3.407.1-143: размеры стоек и несущая способность анкерных, концевых и ответвительных опор.

# 6. Режим проверки

1. Загрузите отчёт по п. 13 на странице «Исходные данные».
2. Внесите параметры из проверяемого проекта (кабель, провода, высоты подвеса, муфты) на страницах «Расчёты» и «Решения» — либо загрузите файл проекта PD_RD от проектировщика на странице «Проверка проекта».
3. Отметьте состав представленной документации, нажмите «Сформировать замечания» и скачайте лист замечаний (DOCX) — каждое замечание со ссылкой на норму.

# 7. Демо-проект

Кнопка «Открыть демо-проект» на главной странице загружает вымышленный проект (31 опора) с выполненными импортом, расчётом и решениями. Он предназначен для знакомства с инструментом и проверки после обновлений. Конфиденциальные отчёты в инструмент встроены не будут.

# 8. Обновление сайта

Все файлы сайта лежат в корне репозитория; при обновлении загружаются поверх с заменой. Папку `build/` загружать на сайт не требуется — она нужна только для пересборки шаблонов.

После обновления откройте страницу «Тесты»: все проверки должны быть пройдены.

# 9. Ограничения версии 1.0.0

- Проект полосы отвода при необходимости ДПТ программой не формируется — прикладывается отдельно.
- Смета не формируется — только пояснение или обоснование отсутствия.
- Координаты в DXF — в миллиметрах листа; пересчёт в МСК-23 — по запросу, при наличии параметров. Растровая подложка в DXF не выгружается.
- Документацию утверждает заместитель директора по развитию и технологическому присоединению А.В. Чепусов (гриф «УТВЕРЖДАЮ» на титульных листах и строка «Утв.» в основной надписи).
- Значения справочника опор АРМ ППО (допустимые моменты, габаритные пролёты) — типовые и подлежат сверке с альбомами типовых проектов.
