# PD_RD — ПД и РД на размещение ВОЛС на опорах ВЛ 0,4–110 кВ

Филиал ПАО «Россети Юг» — «Кубаньэнерго», ДРНУ. ГИП — Е.В. Куличкин.

Инструмент собирает комплект проектной и рабочей документации из отчёта по п. 13 Правил
(ПП РФ № 2106), выпущенного [АРМ ППО ВОЛС](https://github.com/Anatoliy031/VOLS_ARM_V25),
технического задания оператора и проектных решений. Работает целиком в браузере, данные
никуда не передаются.

Сайт для проверки: https://anatoliy031.github.io/PD_RD/

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | Точка входа: основная надпись проекта, резервная копия, ход разработки |
| `tests.html`, `pdrd-tests.js` | Автотесты (работают на временном хранилище) |

| `pdrd-norms.js` | Реестр документов и значений со ссылками на пункты |
| `pdrd-profiles.js` | Профили операторов: Ростелеком (пилот), МТС, ВымпелКом |
| `pdrd-marks.js` | Состав ПД по п. 32 ПП № 87, обозначения томов (не утверждены) |
| `pdrd-ui.css` | Оформление |
| `Karta_poley_V25.md` | Карта полей АРМ ППО → PD_RD (этап 0, утверждена) |
| `CLAUDE.md` | Инструкция разработки |
| `.nojekyll` | Отключает обработку Jekyll. Не удалять |

Файлы лежат в корне, без папок. `index.html` не переименовывать.

## Сохранность данных

Проект хранится в браузере под ключами `pdrd_*`. Данные АРМ ППО PD_RD только читает.
Перед очисткой истории браузера сохраните копию: «Сохранить копию в файл» (`.pdrd`).

## Изменения версии 0.2.0

* Карта полей утверждена: оператор связи и подрядчик — разные стороны. В проекте появились
  поля «оператор» и «подрядчик»; запись АРМ ППО «ООО … в интересах ПАО …» разбирается автоматически.
* Реестр норм `pdrd-norms.js`: 62 документа, 22 нормируемых значения, у каждого — документ и пункт.
  Сверены с первоисточником: ПП № 87 (ред. от 21.10.2025, действует до 01.09.2028),
  ГОСТ Р 21.617-2023, ГОСТ Р 21.618-2023, ТТ № 282р, ПТ-029-4.
* Расстояние ОКСН — провод выбирается по классу напряжения и типу провода. Для голого провода
  0,4 кВ значение не подставляется: это пробел ТТ № 282р.
* ГОСТ 13276-79 отмечен как заменённый ГОСТ Р 51177-2017; ссылки на него находятся в тексте.
* ГОСТ Р 21.618-2023 отмечен как неприменимый к трассе ВОЛС.
* Состав ПД — 10 разделов по п. 32; обозначения томов — предложение, не утверждены.
* Профили операторов: Ростелеком B2C/GPON (пилот), МТС, ВымпелКом.
* Страница «Нормы». Автотестов — 23.

## Изменения версии 0.1.0

* Создан репозиторий, ядро `pdrd-core.js`: модель проекта, сохранение, резервная копия
  в файл и открытие из файла, проверка схемы.
* Защита общего адреса: запись разрешена только в ключи `pdrd_*`; попытка записать
  в ключ АРМ ППО отклоняется.
* Чтение осмотра АРМ ППО без изменения его данных.
* Предварительный перечень пробелов, блокирующих выпуск (шифр, марки, подписи, СРО, отчёт, кабель).
* Автотесты ядра — 10 проверок.
* Этап 0: карта полей АРМ ППО → PD_RD.
