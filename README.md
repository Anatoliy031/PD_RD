# PD_RD — ПД и РД на размещение ВОЛС на опорах ВЛ 0,4–110 кВ

Филиал ПАО «Россети Юг» — «Кубаньэнерго», ДРНУ. ГИП — Е.В. Куличкин.

Инструмент собирает комплект проектной и рабочей документации из отчёта по п. 13 Правил
(ПП РФ № 2106), выпущенного [АРМ ППО ВОЛС](https://github.com/Anatoliy031/VOLS_ARM_V25),
технического задания оператора и проектных решений. Работает целиком в браузере, данные
никуда не передаются.

Сайт для проверки: https://anatoliy031.github.io/PD_RD/

## Сохранность данных

Проект хранится в браузере под ключами `pdrd_*`. Данные АРМ ППО PD_RD только читает.
Перед очисткой истории браузера сохраните копию: «Сохранить копию в файл» (`.pdrd`).

## Как устроены шаблоны

Оформление по ГОСТ Р 21.101-2020: титульный лист без рамки; далее рамка 20/5/5/5 мм,
основная надпись формы 5 (185×40 мм) на первом листе и формы 6 (185×15 мм) на последующих.
Шрифт — Arial.

Поля: `{{ПОЛЕ}}`, `{{ТАБЛИЦА:ИМЯ}}`, `{{БЛОК:ИМЯ}}`, `{{ЕСЛИ:УСЛОВИЕ}}…{{КОНЕЦ}}`.
Незаполненное поле печатается прочерком и попадает в перечень пробелов — выпуск блокируется.
Пока шифр не утверждён, на листах стоит отметка «ШИФР НЕ УТВЕРЖДЁН».

Пересборка шаблонов (на компьютере с Python 3): `python3 build/b1_templates.py`.

## Конфиденциальность исходных данных

Отчёты по п. 13 конфиденциальны (п. 15 Правил). В репозиторий они не загружаются:
репозиторий публичный. Проверка на пилотном отчёте выполняется локально, в автотестах —
синтетические данные.

## Изменения версии 0.5.0

* Расчётное ядро по ПУЭ-7 (текст сверен по полному тексту 7-го издания из файлов проекта):
  нагрузки от веса, гололёда и ветра (пп. 2.5.41–2.5.55), коэффициенты надёжности для
  проводов и для опор (пп. 2.5.54, 2.5.55, 2.5.62, 2.5.65, 2.5.69, 2.5.70), особенности ВЛ до 1 кВ
  с ОКСН (п. 2.4.11), режимы п. 2.5.71 и температуры п. 2.5.51.
* Уравнение состояния, подбор тяжения по наиболее нагруженному режиму, монтажные таблицы
  с шагом 5 °C по анкерным участкам, габарит до земли при наибольшей стреле, расстояние
  до проводов в пролёте, свободные интервалы на опоре, моменты на опоры с учётом всех линий
  совместной опоры, длина кабеля.
* Анкерные участки строятся по неориентированному графу ссылок «пред./след.» — в отчёте
  направление обхода на разных участках различается.
* Углы поворота определяются по координатам; углы больше 90° помечаются как вероятная ошибка ссылок.
* Анкерные, концевые и ответвительные опоры с подкосами проверяются по несущей способности
  конструкции из типового проекта, а не по моменту одиночной стойки.
* Нет исходных данных — нет результата: опора получает статус «нет данных» и попадает
  в сводный перечень недостающих данных.
* Расстояние ОКСН — неизолированные провода ВЛ до 1 кВ: 0,4 м по ПУЭ-7, п. 2.4.89
  (пробел ТТ № 282р закрыт первоисточником).
* В реестре исправлены коэффициенты: γf по ветру при расчёте кабеля — 1,1 (п. 2.5.54),
  1,3 — только для нагрузок на опоры (п. 2.5.62). В приложении Ж пилотного отчёта
  для ветра указано 1,3 без разделения.
* Результаты расчёта попадают в тома: таблицы «Пролёты», «Нагрузки» и вывод по опорам.
* Автотестов — 71, в том числе контрольные примеры с ручным счётом.
